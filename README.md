# Mesen Community Edition DEBUG FORK

Mesen is a multi-system emulator for Windows. It supports NES, SNES, Game Boy (GB/SGB/GBC), Game Boy Advance, PC Engine, SMS/Game Gear, and WonderSwan (WS/WSC).

This is a community managed debug fork, created to maintain and expand this emulator into the future.
